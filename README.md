# Room-Escape

## App Features:
- Unlimited levels.
- Infinite game mode.
- Player statistics.
- Achievements and daily quests.
- Leaderboard, to compete with other players.
- Save and load data on server or offline.
- Register, log in system.
- The player can choose different materials for the game.
- Shop, where the player can buy some materials using their coins.
- Contains ads.
- Contains in app purchases.
- Player can revive with coins or ads if lose.
